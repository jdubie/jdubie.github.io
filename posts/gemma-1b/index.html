Teaching Gemma 1B

Small, cheap post-training experiments on one 1B model. Each one asks what supervised fine-tuning or reinforcement learning can teach it, and each costs under $100 on a single accelerator.

The pattern so far: SFT teaches a procedure when the target spells out the intermediate steps, and RL sharpens what the model can already do sometimes. Neither helped when the model could not do the task at all.

SFT

Counting letters

Base 20% → 84% after fine-tuning the model to spell the word out before counting.

RL

Made-up puzzles

33–59% → 96–100% with 45 minutes of GRPO; gains carry over to harder unseen variants.

Short read

Gemma 1B won’t fix its own code

It resubmits the same failing code 95% of the time; starting over works far better than asking it to fix.
