  • November 10, 2026 Coding agents stacking blocks with a robot arm

    Six coding agents each got 20 minutes and a 300 Hz socket to a simulated YAM arm; Opus 5.5 and GPT-6.1 Sol both stacked all eight blocks.

  • November 15, 2026 Find every duplicate file, as fast as you can

    Six coding agents had 15 minutes, six times each, to write the fastest correct duplicate-file finder for 23 hidden trap trees. Opus was fastest on average; Gemini matched it when it finished.

  • October 12, 2026 Make the tests faster, without breaking them

    An RL environment that rewards coding agents to speed up a slow client-server test suite only if it still catches 24 hidden bugs, where Gemini 4 Argon reached 40.8x and Opus 10.3x against a hand-written 78.7x. Grok 4.7 scored 0: its suite was 23.5x faster and caught every bug, but it loosened a rate limit to get there.

  • November 14, 2026 How good are agents at robotic control?

    An agent benchmark where models get 8 minutes and a socket to a simulated YAM arm whose dynamics are hidden, and must make it follow 14 trajectories. Sol (gpt-6.1-sol) reached 0.10 mm, better than a controller that knows the true dynamics; the Claude models stopped early.
