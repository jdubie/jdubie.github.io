# yam-track: where it stands (2026-11-14)

**Layout.** `sim/` is the true arm (`core.py`), the socket server (`server.py`) and the fixed eval/practice sets
(`evalset.py`). `env.py reset --version v1|v2` builds a run and writes the agent prompt (`prompts/v1.md`, `v2.md` are
the prompts the sweep agents actually got). `live/harness.py run --version` runs a model in a container.
`public/` holds the tools the agent sees. `qa/` holds baselines, the per-term sensitivity check and page generators.

**Metric.** RMS mm of three points (wrist centre, TCP 11.5 cm out, a point 6 cm off the gripper axis), on the true
arm's FK at 1500 Hz. v1 scores the best finished trial per eval reference; a reference never finished counts as limp.
v2 scores `controller.py` on the hidden eval set.

**Eval set.** 14 references: 8 targeted (`gravity_holds/reach`, `friction_reversals/dither/speeds`,
`inertia_proximal/wrist`, `coriolis_spin`) and 6 recorded 12 s right-arm windows. The sensitivity check (oracle
with one term set to nominal) confirms that each term's targeted test is where getting that term wrong costs most.

**Baselines (5 robots).** PD 40 mm, nominal frame-aware feedforward 4.8 mm, oracle (true parameters) 0.14 mm.
